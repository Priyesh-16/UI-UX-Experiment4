# UI-UX-Experiment4

## Aim:

To design a low-fidelity wireframe for a generic application/website using Balsamiq Wireframes with 5 essential screens: Splash, Login/Signup, Home, Product Listing, and Checkout/Contact screen.

## Algorithm:

1.Open Balsamiq Wireframes and create a new project.

2.Design the Welcome/Splash screen with logo and start button.

3.Create the Login/Signup screen with input fields and buttons.

4.Design the Home/Dashboard screen with navigation and main features.

5.Create the Product/Content Listing screen with search and item cards.

6.Design the Checkout/Contact screen with form details and submit button.

7.Review and save the wireframe.
